api API Documentation

Welcome to the Course Registration System API. This RESTful API provides programmatic access to manage students, modules, and registrations.

Base URL
{{ request.build_absolute_uri }}api/
Content Type

All requests and responses use JSON format.

Content-Type: application/json
Authentication

Currently, the API uses session-based authentication. Future versions will support token authentication.

Authentication Requirements

Most endpoints require user authentication. Ensure you're logged in before making API calls.

// Include session cookies in your requests
fetch('/api/students/', {
    credentials: 'same-origin',
    headers: {
        'X-CSRFToken': getCsrfToken()
    }
});
Students
GET /api/students/

Retrieve a list of all students (admin only).

Response Example:
[
    {
        "id": 1,
        "user": {
            "username": "john_doe",
            "email": "john@example.com",
            "first_name": "John",
            "last_name": "Doe"
        },
        "student_id": "STU001",
        "date_of_birth": "1995-06-15",
        "phone_number": "+1234567890",
        "is_verified": true,
        "date_created": "2024-01-15T10:30:00Z"
    }
]
GET /api/students/{id}/

Retrieve details of a specific student.

Parameters:
  • id (integer): Student ID
Modules
GET /api/modules/

Retrieve a list of all available modules.

Query Parameters:
  • search (string): Search by title or code
  • category (string): Filter by category
  • is_active (boolean): Filter by active status
Response Example:
[
    {
        "id": 1,
        "code": "CS101",
        "title": "Introduction to Computer Science",
        "description": "Basic concepts of computer science...",
        "credits": 3,
        "category": "Computer Science",
        "instructor": "Dr. Smith",
        "start_date": "2024-02-01",
        "end_date": "2024-05-15",
        "max_students": 30,
        "enrolled_count": 25,
        "is_active": true
    }
]
GET /api/modules/{id}/

Retrieve details of a specific module.

Registrations
GET /api/registrations/

Retrieve registrations for the current user.

Response Example:
[
    {
        "id": 1,
        "module": {
            "id": 1,
            "code": "CS101",
            "title": "Introduction to Computer Science",
            "credits": 3
        },
        "status": "enrolled",
        "date_registered": "2024-01-15T10:30:00Z",
        "is_active": true
    }
]
POST /api/registrations/

Register for a new module.

Request Body:
{
    "module_id": 1
}
DELETE /api/registrations/{id}/

Withdraw from a module (sets status to withdrawn).

Error Codes
HTTP Status Codes
  • 200 OK - Request successful
  • 201 Created - Resource created successfully
  • 400 Bad Request - Invalid request data
  • 401 Unauthorized - Authentication required
  • 403 Forbidden - Permission denied
  • 404 Not Found - Resource not found
  • 500 Internal Server Error - Server error
Error Response Format:
{
    "error": "Error message",
    "details": "Additional error details",
    "code": "ERROR_CODE"
}
